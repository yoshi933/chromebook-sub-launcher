# My Chromebook Launcher

Chromebookのシェルフに固定したアプリやショートカットを、Chromebook風の画面でまとめて起動するサブランチャーです。**単一の `index.html`** だけで動作し、データはブラウザのローカルストレージに保存されます。

## できること

- アプリ／ショートカットの追加・編集・削除
- URL登録時にPWAの `manifest.json` アイコンを優先取得（取得できない場合はapple-touch-icon／faviconへフォールバック）
- ドラッグ＆ドロップによる並び替え、星ボタンによる上部固定
- カテゴリ／フォルダ名を設定し、カテゴリタブで絞り込み
- 最近使ったアプリの表示
- 起動直後から検索バーへ入力可能、矢印キーでアプリ選択、Enterで起動
- 矢印キーはカードの実際の画面座標を使って移動するため、画面幅や折り返しに追従
- 検索結果を名前の一致度、最近の利用、利用回数の順で優先表示
- 手動テーマ設定（端末設定に合わせる／ライト／ダーク）
- アプリ起動後にランチャーを閉じる設定（ブラウザが許可する場合のみ）
- JSONで設定をバックアップ／別のChromebookへ移行

## GitHub Pagesで公開

1. GitHubの **Settings → Pages** を開く
2. **Build and deployment** で **Source: GitHub Actions** を選ぶ
3. `Deploy to GitHub Pages` ワークフローが完了すると、次のURLで利用できます

   `https://yoshi933.github.io/chromebook-sub-launcher/`

4. ChromebookでURLを開き、Chromeのメニューから **「保存して共有」→「ページをアプリとしてインストール」**（またはショートカット作成）を選びます。

## 使い方

アプリ追加・編集時にカテゴリ／フォルダ名を入力できます。画面上部のカテゴリタブで表示を絞り込めます。カテゴリを空欄にした場合は「未分類」になります。

右上の歯車からテーマを変更できます。テーマはこのブラウザに保存されます。「アプリ起動後、このランチャーのタブを閉じる」を有効にすると、アプリ起動後に `window.close()` を試みます。ただし、通常のブラウザタブをユーザー操作で開いた場合など、ブラウザの安全制限で閉じられないことがあります。

設定はそのブラウザ内だけに保存されます。端末変更やデータ消去に備えて、**設定・アプリ管理 → JSONを書き出す** を利用してください。

## 注意

外部サイトがCORSを許可していない場合、manifest.jsonやHTMLからのアイコン取得はブラウザによって制限されます。その場合はGoogleのファビコンへフォールバックします。起動時は新しいタブで登録URLを開きます。
